# Assets

| Folder | What | Notes |
|---|---|---|
| `capri/` | Capri's sprite sheets (the pet's default body) | **Source of truth.** ViviPet gets a copy via `integrations/capri/fetch_capri_assets.ps1` |
| `previews/capri/` | Pose sheets and sprite-sheet overviews of Capri | `poses-<date>.png` is the newest capture |
| `previews/chibi/` | Pose sheets of the code-drawn chibi, v1 → v5 | History of the chibi redesign |
| `previews/*/frames/` | Individual captured frames | Regenerated by every capture run, so not in git |

## Changing or checking the character

- **Swap or edit a sprite:** replace the PNG in `capri/` (same name and frame layout), then run
  `integrations\capri\fetch_capri_assets.ps1` (syncs into ViviPet) and `npm run build:renderer` in ViviPet's `apps\desktop`.
  Each sheet is one row of equal frames. The frame counts and fps are listed at the top of ViviPet's `SpriteRenderer.ts`:
  idle 16, blink 4, grin 16, mouth 5, glitch 10, dangle 24, sleep 16, wake 13, dance 16, arrive 14.
- **See every pose:** with the pet running, run `.venv\Scripts\python tools\preview\capture_poses.py` (add `--model capri` or
  `--model vivi-chibi` to switch first). It saves frames plus a new `previews/<model>/poses-<date>.png`.
- **Inspect raw sheets:** `tools\preview\contact.py <sprites_dir> <out.png> idle:16 grin:16 ...` lays out frames from each strip.
